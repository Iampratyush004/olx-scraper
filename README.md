# OLX Car Cover Scraper

This repository contains a simple Python script to scrape **Car Cover** listings from [OLX India](https://www.olx.in/items/q-car-cover) and save the results into a text file.

## 📌 Features
- Fetches the OLX search results page for "Car Cover"
- Extracts listing titles and links
- Saves results into a tab-separated file (`olx_car_covers.txt`)

## 🛠️ Requirements
- Python 3.7+
- [requests](https://pypi.org/project/requests/)
- [beautifulsoup4](https://pypi.org/project/beautifulsoup4/)

Install dependencies:
```bash
pip install -r requirements.txt
